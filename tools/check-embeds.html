Which links actually play in the page

Open this with the site running (npm run serve, then 127.0.0.1:8000/tools/check-embeds.html). It asks YouTube about every link in js/data/letters.js and reports which ones are allowed to play outside YouTube. Nothing here changes the site: a letter marked links out still works, it just shows a "Listen on YouTube" button instead of a player. Takes about ten seconds.
